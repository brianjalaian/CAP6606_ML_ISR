# Module 5: Dimensionality Reduction

High-dimensional data is hard to visualize, slow to train on, and prone to overfitting. This module covers compressing data onto lower-dimensional subspaces while keeping the structure that matters.

## What You'll Learn

- Principal component analysis (PCA) for unsupervised compression
- Linear discriminant analysis (LDA) for supervised, class-separating projections
- Nonlinear dimensionality reduction and manifold learning (t-SNE)
- How to choose the number of components and interpret explained variance
