# Module 1: Ensemble Methods

This module covers ensemble learning techniques—combining multiple models to achieve better predictive performance than any single model alone.

## What You'll Learn

- Why single models fail and how ensembles help
- Voting and bagging as foundational techniques
- Random Forests for tabular data
- Gradient Boosting and its variants
- Feature importance and model interpretation
