# Module 4: Data Preprocessing

Models are only as good as the data they train on. This module covers building good training datasets: handling missing values, encoding categorical data, scaling features, and selecting the ones that matter.

## What You'll Learn

- Identifying and imputing missing data
- Encoding ordinal and nominal categorical features
- Feature scaling: normalization vs. standardization
- L1/L2 regularization as implicit feature selection
- Sequential feature selection and feature importance with random forests
