# Module 2: Linear Classifiers

This module builds the first trainable models of the course from scratch: the perceptron and adaptive linear neurons (Adaline). These simple algorithms introduce the two ideas everything later depends on — decision boundaries and gradient-based learning.

## What You'll Learn

- The perceptron learning rule and its convergence behavior
- Adaline and minimizing a continuous loss with gradient descent
- Batch vs. stochastic gradient descent
- Feature scaling and why it matters for optimization
- Implementing a classifier in NumPy from first principles
