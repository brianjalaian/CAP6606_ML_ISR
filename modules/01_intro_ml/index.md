# Module 1: Introduction to Machine Learning

This module frames the whole course: what machine learning is, the three broad learning paradigms, and the terminology and workflow we will use for the rest of the semester.

## What You'll Learn

- Supervised, unsupervised, and reinforcement learning — and when each applies
- The basic terminology: samples, features, labels, training, inference
- The canonical ML workflow: preprocessing → training → model selection → evaluation
- A roadmap of the techniques covered in this course
