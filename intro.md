# Machine Learning for Intelligent Systems & Robotics

Welcome to CAP 6606, a graduate course at the University of West Florida taught by Dr. Brian Jalaian. The course starts with classical machine learning and works up through deep learning to Transformers, reinforcement learning, and large language models. Every module is built around code you can run yourself.

```{important}
Bookmark this site and check back each week for new modules, notebooks, and lecture videos.
```

## How to Use This Book

- Work through the modules in order from the left sidebar. Each one builds on the last.
- Every module has an overview page with learning objectives and lecture notes, plus a chapter notebook.
- Launch any notebook in Google Colab or Kaggle with the badges at the top. Nothing to install.
- Recorded lecture videos are embedded on the module pages as they are released.
- Use the "Edit This Page" button to suggest fixes or improvements on GitHub.

## What the Course Covers

**Foundations of machine learning (Modules 1–6).**
What learning from data means, linear classifiers, the scikit-learn toolkit, data preprocessing, dimensionality reduction, and how to evaluate and tune a model honestly.

**Classical methods in practice (Modules 7–10).**
Ensemble methods, sentiment analysis on real text, regression, and clustering.

**Deep learning (Modules 11–14).**
Neural networks from scratch, PyTorch, convolutional networks for images, and recurrent networks for sequences.

**Modern AI (Modules 15–17).**
Transformers and attention, reinforcement learning, and large language models.

## Learning Outcomes

By the end of the course you will be able to:

1. Choose an appropriate learning approach (supervised, unsupervised, or reinforcement) for a given problem.
2. Build, evaluate, and tune classical models with scikit-learn, avoiding common pitfalls such as data leakage and overfitting.
3. Implement and train neural networks, CNNs, and RNNs in PyTorch.
4. Explain how Transformers and large language models work, and use them in your own projects.
5. Judge whether a reported result is real by applying sound evaluation practice.
